# TourFriendly

A full-stack tourism platform for exploring Karnataka.

## 🌐 Live Website

👉 https://tourfriendly.onrender.com

## 💻 GitHub Repository

👉 https://github.com/roshan23094-coder/TourFriendly-2.0

## 🚀 Features

- Explore Karnataka districts
- Discover tourist destinations
- Browse hotels
- Hotel booking
- Wishlist
- User authentication
- AI Trip Planner
- Search and filtering
- Admin dashboard
- Responsive React UI
- MongoDB database
